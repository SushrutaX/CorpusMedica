# Glossary

- Voxel: A 3D pixel representing a volume element.
- NIfTI: A neuroimaging file format for 3D medical images.
- DICOM: Standard format for medical imaging data and metadata.
- Modality: Imaging type such as MRI or CT.
- ROI: Region of interest used for inference or display.
- Colormap: Mapping of intensity values to colors.
- Iso-surface: A surface extracted from a volume at a constant value.
- Mesh: A surface representation built from vertices and faces.
- Affine: Matrix describing voxel-to-world alignment.
